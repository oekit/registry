## 安装

```bash
go get github.com/oekit/registry@v0.2.6
```

## 这个仓库做什么

`registry` 是**注册发现与配置的基础设施层**：provider 无关的服务注册/发现/订阅/配置
SPI、Nacos 落地实现、Nacos 客户端门面、YAML/env 配置加载，以及跨框架的服务发现桥接。

## 组成

| 包 | 做什么 |
|---|---|
| `registry` | SPI：`Registrar`/`Discoverer`/`Subscriber`/`ConfigStore` + 实例模型 + 注册地址解析（netutil）。hertz/kitex 适配器面向它编程 |
| `registry/nacos` | Nacos 实现（nacos-sdk-go v2） |
| `registry/sdbridge` | 服务发现适配器共享核心（拉取+校验+错误包装），oekit/hertz 与 oekit/kitex 复用 |
| `registrymocks` | 四接口的统一测试 mock |
| `nacos` | Nacos 客户端门面（nns 默认构造用） |
| `config` | YAML 配置加载（`LoadBootstrap[T]` 自动选 etc/config-{env}.yaml）、环境变量、.env、merge |

## 快速使用

```go
import nacosimpl "github.com/oekit/registry/registry/nacos"

reg, _ := nacosimpl.NewRegistrar(namingCli)    // 服务注册
disc, _ := nacosimpl.NewDiscoverer(namingCli)  // 服务发现
```

```go
import "github.com/oekit/registry/config"

cfg, _ := config.LoadBootstrap[MyConfig]("dev") // etc/config-dev.yaml
port := config.GetIntWithDefault("PORT", 8080)
```

## 边界

- Kitex/Hertz 的注册发现适配器分属 [kitex](https://github.com/oekit/kitex) 与 [hertz](https://github.com/oekit/hertz)
- 服务治理高级语义（熔断/换实例重试）在 [nns](https://github.com/oekit/nns)
